1.Mesh Utilities (works in both add-ons)

Batch rename, apply rotation/scale, recalculate normals, and create collision proxies — the same toolset, available standalone in either add-on.

Apply Rotation / Apply Scale. Bakes Rotation (or Scale) into the mesh data on every selected object while preserving the other transforms, across a multi-selection at once.

Fix Normals Per UV Island. Recalculates normals outward per UV island using a radial direction, independent of mesh topology — works even when a few bad faces are surrounded by correct ones (non-manifold gaps), which is exactly where Blender's own Recalculate Outside or Merge+Recalculate tends to fail.

Apply MNEMO Naming Convention. Batch-renames selected meshes with the MNEMO prefix system (Island_ / Building_ / Landscape_) plus the original name and an index, so exported meshes get their Tag and Collision behavior auto-assigned in UE. A Custom mode is also available for a freeform prefix with no auto-assignment.

Create Proxy Collision (Convex Hull). Duplicates a selected MNEMO-named mesh and replaces each separate piece with its own Convex Hull — always clean regardless of errors in the source mesh. It's named so UE auto-detects it, enables Collision, and hides it from render.

Convert Triangles to Quads. Merges adjacent triangle faces back into quads (same as Blender's own Tris to Quads) — fixes visible diagonal seams across rectangular faces such as glass panes.

Join Meshes (Ctrl+J) / Split Joined Mesh (by Loose Parts). A matched pair: Join combines selected meshes into one object; Split reverses a Join back into its original separate pieces — only works on parts that weren't actually welded together.

Note: this exact toolset is shared code between BlendReal — Cinematic Pipeline UE5 and BlendReal — Spaceship Traffic, which is why it's covered once here instead of twice.

2.Exhaust Trail Export — Spaceship Traffic → Unreal Niagara

Transfer spaceship engine exhaust trails from Blender straight into Unreal Engine's Niagara system.

Compute & Preview Trail Points. Scans selected ships (or whole collections) and computes exhaust trail marker points along their already-baked flight paths, previewable directly in Blender before exporting anything.

Trail Include/Exclude Checklist. Pick exactly which ships or collections should get a trail, instead of an all-or-nothing switch — useful when only some ships in a shot need visible exhaust.

Niagara Parameters. Trail Height Ratio, Trail Side Ratio, Hot Phase Duration, Noise Intensity, Trail Lifetime, Trail Opacity, and Ribbon Width Ratio, plus separate trail colors per stream (Civilian/Cargo/Military) or a single Trail Color if you're not using the 3-stream split.

Export to Niagara System. Sends the computed trail data directly into your UE project's Niagara System at the path you specify — requires both BlendReal add-ons installed.

Update Trail Params / Update Trail Positions (Live). After the first export, push new parameter values or respawn marker positions straight into the already-running UE session without a full re-export.

Scan for Trail Systems / Recompute ALL Ships. Utility tools to find existing trail setups already exported to a folder and reuse them, or force-recompute every ship's marker positions from scratch if something changed upstream — for example, if flight paths were re-baked after the trail was first computed.
